# Role Based Access Portal

A Full stack Role Based Access Portal built using Angular and Node.js.

# Features

User Login Authentication
Role Based access Control
Admin Dashboard
General User Dashboard
User Management System

# Tech Stack

Angular
TypeScript
Node.js
Express.js
HTML
CSS

# Project Structure

Client - Frontend Application
Server - Backend API

# Output

Project Output screenshots are included in the repository as Login-page 1.png, Login-page 2.png, admin-dashboard 1.png, admin-dashboard.png, user-dashboard.png

# Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

# Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.

# Running the Project

Frontend
   cd client 
   npm install
   ng serve

Backend
   cd server
   npm install
   npm start

# Running unit tests

Run `ng test` to execute the unit tests via [Karma](https://karma-runner.github.io).

## Further help

To get more help on the Angular CLI use `ng help` or go check out the [Angular CLI Overview and Command Reference](https://angular.io/cli) page.
